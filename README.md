# テキスト比較アプリ

Next.jsとReactを使用して作成されたテキスト比較アプリケーションです。2つのテキストを入力して、リアルタイムで差分を表示できます。

## 機能

- 2つのテキストをリアルタイムで比較（左右表示 / 上下表示の切り替え）
- 差分の強調単位を選択（文字 / 単語 / 行のみ）。日本語の文章は「文字」がおすすめ
- 無視する違いの指定
  - 全角/半角（「１２３」と「123」、「ｶﾅ」と「カナ」）
  - 大文字/小文字
  - 空白（全角スペース・タブ・行頭行末の空白）
  - 空行
  - 改行コード（CRLF/LF）の違いは常に無視
- 差分のある箇所だけを表示（同じ行は折りたたみ）
- 追加・削除・一致の行数を表示
- ファイル読み込み（ボタンまたはドラッグ＆ドロップ）。文字コードは UTF-8 / UTF-16 / Shift_JIS / EUC-JP を自動判別
- A/B の入れ替え、サンプルデータ、個別クリア
- 差分（unified形式）のコピー・ファイル保存

### データの取り扱い

入力したテキストはブラウザ内だけで処理され、サーバーへの送信やブラウザへの保存は行いません。
保存されるのは表示設定（表示方法・無視する違いなど）のみです。

ページ下部に楽天アフィリエイトの広告を掲載しています。広告画像は楽天のサーバーから読み込まれますが、入力したテキストが広告側に送られることはありません。

## 技術スタック

- **Next.js 15** - Reactフレームワーク
- **React 19** - UIライブラリ
- **TypeScript** - 型安全性
- **Tailwind CSS** - スタイリング
- **react-diff-viewer-continued** - 差分表示コンポーネント
- **diff** - 行数統計・unified形式の出力

## セットアップ

1. 依存関係をインストール:
```bash
npm install
```

2. 開発サーバーを起動:
```bash
npm run dev
```

3. ブラウザで [http://localhost:3000](http://localhost:3000) を開く

## 使用方法

1. 左右のテキストエリアにテキストを入力・貼り付け、またはファイルをドロップ（「サンプル」ボタンで例を表示）
2. 必要に応じて「表示」「強調単位」「無視する違い」を設定
3. 下部の差分表示エリアで差分を確認
4. 「差分をコピー」「差分を保存」で結果を取り出し

## ビルド

本番用ビルドを作成:
```bash
npm run build
```

ビルドされたアプリケーションを起動:
```bash
npm start
```
